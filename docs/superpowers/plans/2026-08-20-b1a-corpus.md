# B1a — Corpus Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the snapshotted legal corpus — a content-addressed, git-tracked store of primary legal text with provenance-bearing relationship edges, a bounded entitlement closure over it, and a mechanical evidence checker — so that later plans can verify encoded requirements against text that provably did not move.

**Architecture:** A data directory (`backend/engine/corpus/`) holds raw fetched bytes, normalized text, and an index describing both plus the edges between documents. A code directory (`backend/engine/src/corpus/`) holds the schema, the deterministic text-transformation layer, the loader with integrity checks, the closure computation, and the evidence checker. One CLI (`src/cli/ingest.ts`) is the only component that touches the network. This mirrors the existing `monitoring/` (data) versus `src/monitoring/` (code) split.

**Tech Stack:** TypeScript (strict, ESM), zod for schema validation, vitest for tests, tsx for CLI execution, `node:crypto` for hashing. No new runtime dependencies.

## Global Constraints

- **No new runtime dependencies.** `zod` is the only one permitted. `node:*` builtins are fine. (`backend/engine/CLAUDE.md` → Style)
- **TypeScript strict, with `noUncheckedIndexedAccess: true`.** Indexing an array yields `T | undefined`. Every `arr[i]` needs a guard or a non-null assertion justified by a preceding length check.
- **Program-agnostic.** `grep -ri "csrd" backend/engine/src/` must return only comments and docs. No program name may appear in corpus code paths, types, or logic.
- **No `Date.now()` in engine logic.** Dates enter through parameters. The ingest CLI may read the clock, but only at its own entry point, and it passes the date down.
- **All of `npm test` runs offline.** No test may perform a network fetch.
- **Every file starts with a JSDoc block saying *why* the file exists**, not what it does — match `src/monitoring/register.ts` and `src/monitoring/types.ts`.
- **Zod objects are `.strict()`**, so unknown keys are rejected rather than ignored.
- **Commit message style is imperative sentence-case with no prefix** — "Add the corpus index schema", not "feat: add corpus index schema". Match `git log`.
- **No `Co-Authored-By` trailer on any commit.**
- **`npm test` must be green before every commit.** A red suite blocks the commit.

```ts
/**
 * Corpus schema — the snapshotted legal record.
 *
 * A requirement cites `SRC-###` records; this store holds the actual text
 * behind them, byte-pinned, so a signature can name the exact words that were
 * read. Edges are legal claims about how instruments relate, not bookkeeping,
 * so each one carries where it came from and when it was recorded.
 */

/**
 * `references` is the only kind that costs traversal depth; the rest lead to
 * the same law in the form that currently governs it. See closure.ts.
 */
export type EdgeKind = 'amends' | 'amendedBy' | 'consolidates' | 'references' | 'definesTermsFor';

/**
 * `human` is legitimate and expected — not every relation is published as
 * metadata. Labelling it honestly is what makes hand-asserted relations
 * countable rather than indistinguishable from derived ones.
 */
export type EdgeProvenanceType = 'eli_metadata' | 'celex_metadata' | 'human';

export interface EdgeProvenance {
  type: EdgeProvenanceType;
  /** Where the claim came from, in enough detail to re-check it by hand. */
  source: string;
  /** ISO date (YYYY-MM-DD) the relation was recorded. */
  recordedOn: string;
}

export interface CorpusEdge {
  /** Stable identity. Hashed into the closure, so it must not be recycled. */
  edgeId: string;
  kind: EdgeKind;
  /** Always the docId of the document carrying this edge. Validated. */
  from: string;
  to: string;
  provenance: EdgeProvenance;
}

export interface CorpusDocument {
  docId: string;
  /** SRC-### records in a knowledge pack this document is the text behind. */
  serves: string[];
  title: string;
  url: string;
  /** The version that matters legally, e.g. "consolidated 18 Mar 2026". */
  versionLabel: string;
  /** ISO date (YYYY-MM-DD) of retrieval. */
  retrievedOn: string;
  /** Bytes exactly as fetched. Retained so a normalizer change is recoverable. */
  rawPath: string;
  /** The text agents actually read. */
  normalizedPath: string;
  sha256Raw: string;
  sha256Normalized: string;
  /** Which normalizer produced normalizedPath. */
  normalizerVersion: string;
  edges: CorpusEdge[];
}

export interface CorpusIndex {
  /** ISO date the index was last edited. */
  updated: string;
  documents: CorpusDocument[];
}
```

```ts
/**
 * Corpus index validation.
 *
 * Split in two, matching src/monitoring/register.ts: `parseCorpusIndex` checks
 * what a single row can answer for itself, `verifyCorpusIntegrity` checks what
 * needs the whole index. Cycle detection collapses `amends` and `amendedBy`
 * into one directed relation first, because stating the same fact from both
 * ends is documentation, not a loop.
 */

import { z } from 'zod';
import type { CorpusIndex, EdgeKind } from './types';

/** Kinds that lead to the same law in its currently governing form. */
export const STRUCTURAL_EDGE_KINDS: readonly EdgeKind[] = [
  'amends',
  'amendedBy',
  'consolidates',
  'definesTermsFor',
];

const isoDate = z.string().regex(/^\d{4}-\d{2}-\d{2}$/, 'must be an ISO date (YYYY-MM-DD)');
const docId = z.string().regex(/^DOC-[A-Za-z0-9._-]+$/, 'document id must be DOC-*');
const sha256 = z.string().regex(/^[0-9a-f]{64}$/, 'must be a lowercase hex sha-256');

const edgeProvenance = z
  .object({
    type: z.enum(['eli_metadata', 'celex_metadata', 'human']),
    source: z.string().min(1),
    recordedOn: isoDate,
  })
  .strict();

const corpusEdge = z
  .object({
    edgeId: z.string().min(1),
    kind: z.enum(['amends', 'amendedBy', 'consolidates', 'references', 'definesTermsFor']),
    from: docId,
    to: docId,
    provenance: edgeProvenance,
  })
  .strict();

const corpusDocument = z
  .object({
    docId,
    serves: z.array(z.string().regex(/^SRC-\d{3}$/, 'serves entries must be SRC-NNN')),
    title: z.string().min(1),
    url: z.string().url(),
    versionLabel: z.string().min(1),
    retrievedOn: isoDate,
    rawPath: z.string().min(1),
    normalizedPath: z.string().min(1),
    sha256Raw: sha256,
    sha256Normalized: sha256,
    normalizerVersion: z.string().min(1),
    edges: z.array(corpusEdge),
  })
  .strict()
  .superRefine((d, ctx) => {
    for (const e of d.edges) {
      if (e.from !== d.docId) {
        ctx.addIssue({
          code: z.ZodIssueCode.custom,
          message: `${e.edgeId}: edge from ${e.from} is carried by ${d.docId}`,
        });
      }
      if (e.from === e.to) {
        ctx.addIssue({ code: z.ZodIssueCode.custom, message: `${e.edgeId}: edge points at itself` });
      }
    }
  });

const corpusIndex = z
  .object({
    updated: isoDate,
    documents: z.array(corpusDocument),
  })
  .strict();

export class CorpusIntegrityError extends Error {
  constructor(public problems: string[]) {
    super(`Corpus index failed integrity checks:\n - ${problems.join('\n - ')}`);
    this.name = 'CorpusIntegrityError';
  }
}

/** Structural validation plus checks a single row can answer alone. */
export function parseCorpusIndex(raw: unknown): CorpusIndex {
  return corpusIndex.parse(raw) as CorpusIndex;
}

/**
 * Collapse the amendment relation into one direction so that "A amendedBy B"
 * and "B amends A" produce the identical pair, then look for a real loop.
 */
function amendmentPairs(index: CorpusIndex): Set<string> {
  const pairs = new Set<string>();
  for (const d of index.documents) {
    for (const e of d.edges) {
      // Normalised as "amender -> amended".
      if (e.kind === 'amends') pairs.add(`${e.from}->${e.to}`);
      if (e.kind === 'amendedBy') pairs.add(`${e.to}->${e.from}`);
    }
  }
  return pairs;
}

function hasCycle(pairs: Set<string>): boolean {
  const out = new Map<string, string[]>();
  for (const p of pairs) {
    const [from, to] = p.split('->');
    if (from === undefined || to === undefined) continue;
    const list = out.get(from) ?? [];
    list.push(to);
    out.set(from, list);
  }

  const WHITE = 0;
  const GREY = 1;
  const BLACK = 2;
  const colour = new Map<string, number>();

  const visit = (node: string): boolean => {
    if (colour.get(node) === GREY) return true;
    if (colour.get(node) === BLACK) return false;
    colour.set(node, GREY);
    for (const next of out.get(node) ?? []) {
      if (visit(next)) return true;
    }
    colour.set(node, BLACK);
    return false;
  };

  for (const node of out.keys()) {
    if ((colour.get(node) ?? WHITE) === WHITE && visit(node)) return true;
  }
  return false;
}

/** Cross-row checks: identity, resolution, uniqueness, acyclicity. */
export function verifyCorpusIntegrity(index: CorpusIndex): void {
  const problems: string[] = [];

  const docIds = new Set<string>();
  const edgeIds = new Set<string>();
  const paths = new Set<string>();

  for (const d of index.documents) {
    if (docIds.has(d.docId)) problems.push(`${d.docId}: duplicate document id`);
    docIds.add(d.docId);

    for (const p of [d.rawPath, d.normalizedPath]) {
      if (paths.has(p)) problems.push(`${d.docId}: path ${p} is already used by another document`);
      paths.add(p);
    }

    for (const e of d.edges) {
      if (edgeIds.has(e.edgeId)) problems.push(`${e.edgeId}: duplicate edge id`);
      edgeIds.add(e.edgeId);
    }
  }

  for (const d of index.documents) {
    for (const e of d.edges) {
      if (!docIds.has(e.to)) problems.push(`${e.edgeId}: points at unknown document ${e.to}`);
    }
  }

  if (hasCycle(amendmentPairs(index))) {
    problems.push('amendment graph contains a cycle: an instrument cannot transitively amend itself');
  }

  if (problems.length > 0) throw new CorpusIntegrityError(problems);
}
```

```ts
/**
 * Normalization is the floor the whole system stands on: every hash, every
 * quote check and every absence search is computed over its output. It is
 * deliberately minimal — unicode form and whitespace only, plus enough HTML
 * extraction to read what EUR-Lex actually serves. It never lowercases and
 * never rewrites punctuation, because both change legal text.
 */

import { describe, expect, it } from 'vitest';
import {
  extractText,
  normalize,
  normalizeWhitespace,
  NORMALIZER_VERSION,
} from '../src/corpus/normalize';
import { sha256Hex } from '../src/corpus/hash';

describe('text extraction', () => {
  it('strips tags and keeps the text', () => {
    expect(extractText('<p>Article <b>19a</b></p>')).toBe('Article 19a');
  });

  it('drops script and style content entirely', () => {
    const html = '<style>p{color:red}</style><p>Kept</p><script>var x = 1;</script>';
    expect(extractText(html)).toBe('Kept');
  });

  it('turns block boundaries into line breaks so paragraphs do not merge', () => {
    // A closing and an opening tag each yield a break, so blocks end up
    // separated by a blank line. The property that matters is that they do not
    // run together; the exact gap is stable and survives normalization.
    expect(extractText('<p>One</p><p>Two</p>')).toBe('One\n\nTwo');
  });

  it('separates list items the same way', () => {
    expect(extractText('<ul><li>a</li><li>b</li></ul>')).toBe('a\n\nb');
  });

  it('decodes the named entities legal text actually uses', () => {
    expect(extractText('<p>EUR&nbsp;450&nbsp;000 &amp; more &lt;here&gt;</p>')).toBe(
      'EUR\u00a0450\u00a0000 & more <here>',
    );
  });

  it('decodes numeric entities', () => {
    expect(extractText('<p>&#8364;450m</p>')).toBe('€450m');
  });

  it('leaves plain text untouched', () => {
    expect(extractText('Article 19a')).toBe('Article 19a');
  });
});

describe('normalization', () => {
  it('collapses runs of spaces and tabs', () => {
    expect(normalize('EUR   450 \t 000')).toBe('EUR 450 000');
  });

  it('normalises line endings', () => {
    expect(normalize('one\r\ntwo\rthree')).toBe('one\ntwo\nthree');
  });

  it('converts non-breaking spaces to ordinary ones', () => {
    expect(normalize('EUR\u00a0450')).toBe('EUR 450');
  });

  it('applies unicode NFC so decomposed and composed forms agree', () => {
    const decomposed = 'Tu\u0308rkiye'; // u + combining diaeresis
    const composed = 'T\u00fcrkiye'; // precomposed u-umlaut
    expect(decomposed).not.toBe(composed); // different bytes, same word
    expect(normalize(decomposed)).toBe(normalize(composed));
  });

  it('collapses three or more blank lines to one blank line', () => {
    expect(normalize('one\n\n\n\ntwo')).toBe('one\n\ntwo');
  });

  it('preserves case, because case carries meaning in legal text', () => {
    expect(normalize('Large Undertaking')).toBe('Large Undertaking');
  });

  it('preserves dashes, because they appear inside legal identifiers', () => {
    expect(normalize('2013/34/EU — Accounting Directive')).toBe(
      '2013/34/EU — Accounting Directive',
    );
  });

  it('normalizeWhitespace is idempotent', () => {
    // The property the system actually relies on: quote checking and absence
    // search run over already-extracted text, so the comparison form must be
    // a fixed point. Asserted on normalizeWhitespace because that is what
    // those call sites use.
    const once = normalizeWhitespace('EUR\u00a0450   000\r\n\r\n\r\n\r\nx');
    expect(normalizeWhitespace(once)).toBe(once);
  });

  it('normalizeWhitespace leaves entities alone, so it cannot double-decode', () => {
    expect(normalizeWhitespace('&amp;lt;')).toBe('&amp;lt;');
  });

  it('extractText decodes a doubly-escaped entity exactly one level', () => {
    // Republished legal HTML routinely carries these. One pass, one level:
    // running extraction again would wrongly decode the result to '<'.
    expect(extractText('&amp;lt;')).toBe('&lt;');
  });

  it('does not delete text around a bare less-than sign', () => {
```

```ts
/**
 * Hashing, in one place.
 *
 * Every integrity guarantee in the verification system reduces to "this text
 * is still the text that was read", so the digest function lives alone and is
 * used everywhere rather than being re-derived per call site.
 */

import { createHash } from 'node:crypto';

/** Lowercase hex SHA-256. Strings are hashed as UTF-8. */
export function sha256Hex(input: string | Uint8Array): string {
  const bytes = typeof input === 'string' ? new TextEncoder().encode(input) : input;
  return createHash('sha256').update(bytes).digest('hex');
}
```

```ts
/**
 * Raw bytes to readable text.
 *
 * Deliberately minimal. Normalization touches unicode form and whitespace and
 * nothing else: it never lowercases and never rewrites punctuation, because
 * both alter legal text, and a quote check that passes on altered text proves
 * nothing. HTML extraction exists only because EUR-Lex serves HTML.
 *
 * The extractor is honest about its limits: it recovers running text, not
 * table structure or footnote association. Improving it is a NORMALIZER_VERSION
 * bump, which the design already handles as `normalizer_changed` — raw bytes
 * are retained precisely so the improved normalizer can be re-run over them.
 */

/** Bump on any change to extractText or normalize. */
export const NORMALIZER_VERSION = '1.0.0';

/** Entities that actually occur in EU legal text. */
const NAMED_ENTITIES: Record<string, string> = {
  amp: '&',
  lt: '<',
  gt: '>',
  quot: '"',
  apos: "'",
  nbsp: '\u00a0', // decoded faithfully; normalize() collapses it to a space
};

/** Tags after which a line break is needed or paragraphs run together. */
const BLOCK_TAGS =
  'p|div|br|tr|li|h1|h2|h3|h4|h5|h6|section|article|table|thead|tbody|blockquote|dt|dd';

function decodeEntities(text: string): string {
  return text.replace(/&(#x?[0-9a-fA-F]+|[a-zA-Z]+);/g, (whole, body: string) => {
    if (body.startsWith('#x') || body.startsWith('#X')) {
      const code = Number.parseInt(body.slice(2), 16);
      return Number.isNaN(code) ? whole : String.fromCodePoint(code);
    }
    if (body.startsWith('#')) {
      const code = Number.parseInt(body.slice(1), 10);
      return Number.isNaN(code) ? whole : String.fromCodePoint(code);
    }
    return NAMED_ENTITIES[body.toLowerCase()] ?? whole;
  });
}

/**
 * Recover running text from HTML. Plain text passes through unchanged, so this
 * is safe to run over any document.
 *
 * NOT idempotent, and it cannot be: entity decoding turns `&amp;lt;` into
 * `&lt;`, which a second pass would decode again. It is applied exactly once,
 * at ingest, to raw bytes. Anything operating on already-extracted text uses
 * normalizeWhitespace instead.
 */
export function extractText(rawText: string): string {
  if (!/<[a-zA-Z!/]/.test(rawText)) return decodeEntities(rawText);

  let text = rawText;
  // Content of these elements is machinery, not text.
  text = text.replace(/<script\b[^>]*>[\s\S]*?<\/script\s*>/gi, '');
  text = text.replace(/<style\b[^>]*>[\s\S]*?<\/style\s*>/gi, '');
  text = text.replace(/<!--[\s\S]*?-->/g, '');
  // Block boundaries become line breaks before tags are stripped.
  text = text.replace(new RegExp(`<\\s*/?\\s*(${BLOCK_TAGS})\\b[^>]*>`, 'gi'), '\n');
  // A tag-shaped opener is required: `<` followed by a letter or `/`. Legal
  // text says "turnover < 40 million"; a bare `<[^>]*>` deletes everything
  // from that `<` to the next `>`, silently, which is the worst possible
  // failure for a corpus whose whole purpose is that the words did not move.
  text = text.replace(/<\/?[a-zA-Z][^>]*>/g, '');
  return decodeEntities(text).trim();
}

/**
 * Unicode form and whitespace only. Idempotent by construction — it decodes
 * nothing, so there is no second-pass transformation to apply.
 *
 * This is the form comparisons run over, because quote checking and absence
 * search operate on text that has already been extracted, and running full
 * extraction over it again would shift the haystack.
 */
export function normalizeWhitespace(text: string): string {
  let out = text.normalize('NFC');
  // Unicode spaces that are not line breaks become ordinary spaces.
  out = out.replace(/[\u00a0\u1680\u2000-\u200a\u202f\u205f\u3000]/g, ' ');
  out = out.replace(/\r\n?/g, '\n');
  out = out.replace(/[ \t]+/g, ' ');
  out = out.replace(/ *\n */g, '\n');
  out = out.replace(/\n{3,}/g, '\n\n');
  return out.trim();
}

/**
 * The ingest path: raw bytes to the canonical stored form. Applied once per
 * document, never to its own output.
 */
export function normalize(rawText: string): string {
  return normalizeWhitespace(extractText(rawText));
}
```

```ts
/**
 * Corpus loading and integrity.
 *
 * Every load re-derives the stored hashes from the files on disk, so "the text
 * did not move" is checked rather than trusted. A pinned document that has been
 * edited or removed is an integrity failure with its own error type: in an
 * append-only, git-tracked corpus this cannot happen through ordinary drift,
 * so it must not be filed alongside "the law changed".
 */

import { readFileSync } from 'node:fs';
import { isAbsolute, join } from 'node:path';
import type { CorpusDocument, CorpusIndex } from './types';
import { CorpusIntegrityError, parseCorpusIndex, verifyCorpusIntegrity } from './schema';
import { normalize, NORMALIZER_VERSION } from './normalize';
import { sha256Hex } from './hash';

export class CorpusDocumentNotFoundError extends Error {
  constructor(docId: string) {
    super(`Corpus holds no document ${docId}`);
    this.name = 'CorpusDocumentNotFoundError';
  }
}

export interface LoadedCorpus {
  index: CorpusIndex;
  /** Throws CorpusDocumentNotFoundError for an unknown id. */
  document(docId: string): CorpusDocument;
  /** The text agents read. */
  normalizedText(docId: string): string;
  /** The bytes as fetched, decoded as UTF-8. */
  rawText(docId: string): string;
}

function readIfPresent(path: string): string | null {
  try {
    return readFileSync(path, 'utf8');
  } catch {
    return null;
  }
}

/**
 * Reads and validates a corpus directory. `corpusDir` contains index.json and
 * the raw/ and normalized/ trees; document paths are resolved relative to it.
 */
export function loadCorpus(corpusDir: string): LoadedCorpus {
  const indexRaw = readIfPresent(join(corpusDir, 'index.json'));
  if (indexRaw === null) {
    throw new CorpusIntegrityError([`no index.json under ${corpusDir}`]);
  }

  const index = parseCorpusIndex(JSON.parse(indexRaw));
  verifyCorpusIntegrity(index);

  const resolve = (p: string): string => (isAbsolute(p) ? p : join(corpusDir, p));

  const problems: string[] = [];
  const rawText = new Map<string, string>();
  const normalizedText = new Map<string, string>();

  for (const d of index.documents) {
    const raw = readIfPresent(resolve(d.rawPath));
    const norm = readIfPresent(resolve(d.normalizedPath));

    if (raw === null) {
      problems.push(`${d.docId}: raw file ${d.rawPath} is missing`);
    } else if (sha256Hex(raw) !== d.sha256Raw) {
      problems.push(`${d.docId}: ${d.rawPath} does not match sha256Raw`);
    }

    if (norm === null) {
      problems.push(`${d.docId}: normalized file ${d.normalizedPath} is missing`);
    } else if (sha256Hex(norm) !== d.sha256Normalized) {
      problems.push(`${d.docId}: ${d.normalizedPath} does not match sha256Normalized`);
    }

    // The pair must be internally consistent: raw bytes plus the named
    // normalizer must reconstruct the normalized text. A document produced by a
    // different normalizer version is not corrupt — recovering it is the
    // normalizer_changed path, handled in B1b — so the check is skipped there.
    if (raw !== null && norm !== null && d.normalizerVersion === NORMALIZER_VERSION) {
      if (normalize(raw) !== norm) {
        problems.push(`${d.docId}: ${d.rawPath} does not reproduce ${d.normalizedPath} under normalizer ${NORMALIZER_VERSION}`);
      }
    }

    if (raw !== null) rawText.set(d.docId, raw);
    if (norm !== null) normalizedText.set(d.docId, norm);
  }

  if (problems.length > 0) throw new CorpusIntegrityError(problems);

  const byId = new Map(index.documents.map((d) => [d.docId, d]));

  const document = (docId: string): CorpusDocument => {
    const d = byId.get(docId);
    if (d === undefined) throw new CorpusDocumentNotFoundError(docId);
    return d;
  };

  return {
    index,
    document,
    normalizedText: (docId) => {
      document(docId);
      return normalizedText.get(docId) ?? '';
    },
    rawText: (docId) => {
      document(docId);
      return rawText.get(docId) ?? '';
    },
  };
}
```

```ts
/**
 * The entitlement closure — what an agent may read, and what a signature pins.
 *
 * Bounded on purpose. An unbounded transitive walk eventually reaches most of
 * the corpus, and every ingest would then invalidate every signature. The bound
 * is asymmetric because the edge kinds are: structural edges do not lead
 * somewhere new, they lead to the same law in the form that currently governs,
 * so they cost no depth. `references` leads to different law, so it does.
 *
 * Structural edges are followed in both directions — an amending act is needed
 * whether you start from the amended text or the amendment. `references` is
 * followed forwards only: reading an instrument does not require every document
 * that happens to cite it.
 *
 * The hash covers document text hashes AND edge identity and provenance, so a
 * relationship claim cannot be retyped or re-sourced with the documents
 * byte-identical and nothing going stale.
 *
 * referenceDepth: 1 is a v0 hypothesis, not a derived value. B3 measures both
 * evidence excluded by the bound and signature churn under closure change.
 */

import type { CorpusEdge, CorpusIndex, EdgeKind } from './types';
import { sha256Hex } from './hash';

export interface ClosurePolicy {
  /** How many `references` hops from the entry documents are permitted. */
  referenceDepth: number;
  /** Kinds that cost no depth and are followed in both directions. */
  structuralKinds: readonly EdgeKind[];
  /** Kinds that cost a hop and are followed forwards only. */
  referenceKinds: readonly EdgeKind[];
}

export const CLOSURE_POLICY_V0: ClosurePolicy = {
  referenceDepth: 1,
  structuralKinds: ['amends', 'amendedBy', 'consolidates', 'definesTermsFor'],
  referenceKinds: ['references'],
};

export interface Closure {
  /** Sorted. Every document the reader is entitled to open. */
  docIds: string[];
  /** Sorted. Every edge with both endpoints inside the closure. */
  edgeIds: string[];
  /** Covers document text hashes plus edge identity and provenance. */
  sha256: string;
}

/** Documents that hold the text behind the given SRC-### records. */
export function docsForSources(index: CorpusIndex, sourceIds: string[]): string[] {
  const wanted = new Set(sourceIds);
  const found = new Set<string>();
  for (const d of index.documents) {
    if (d.serves.some((s) => wanted.has(s))) found.add(d.docId);
  }
  return [...found].sort();
}

function allEdges(index: CorpusIndex): CorpusEdge[] {
  return index.documents.flatMap((d) => d.edges);
}

/**
 * Breadth-first over the edge graph, tracking reference depth per document and
 * always keeping the shortest one, so a document reached cheaply can still
 * expand structurally even if it was first seen down an expensive path.
 */
export function computeClosure(
  index: CorpusIndex,
  entryDocIds: string[],
  policy: ClosurePolicy = CLOSURE_POLICY_V0,
): Closure {
  const structural = new Set<EdgeKind>(policy.structuralKinds);
  const reference = new Set<EdgeKind>(policy.referenceKinds);
  const edges = allEdges(index);

  const bestDepth = new Map<string, number>();
  const queue: Array<{ docId: string; depth: number }> = [];

  for (const id of entryDocIds) {
    if (!bestDepth.has(id) || (bestDepth.get(id) ?? Infinity) > 0) {
      bestDepth.set(id, 0);
      queue.push({ docId: id, depth: 0 });
    }
  }

  while (queue.length > 0) {
    const item = queue.shift();
    if (item === undefined) break;
    const { docId, depth } = item;
    if ((bestDepth.get(docId) ?? Infinity) < depth) continue;

    for (const e of edges) {
      let next: string | null = null;
      let nextDepth = depth;

      if (structural.has(e.kind)) {
        // Both directions: the amending act is needed from either end.
        if (e.from === docId) next = e.to;
        else if (e.to === docId) next = e.from;
      } else if (reference.has(e.kind) && e.from === docId) {
        if (depth + 1 > policy.referenceDepth) continue;
        next = e.to;
        nextDepth = depth + 1;
      }

      if (next === null) continue;
      if ((bestDepth.get(next) ?? Infinity) <= nextDepth) continue;
      bestDepth.set(next, nextDepth);
      queue.push({ docId: next, depth: nextDepth });
    }
  }

  const docIds = [...bestDepth.keys()].sort();
  const inClosure = new Set(docIds);

  const included = edges
    .filter((e) => inClosure.has(e.from) && inClosure.has(e.to))
    .sort((a, b) => (a.edgeId < b.edgeId ? -1 : a.edgeId > b.edgeId ? 1 : 0));

  const byId = new Map(index.documents.map((d) => [d.docId, d]));

  // Canonical serialisation. Every field that changes what the reader was
  // entitled to know, and nothing that does not.
  //
  // Fields are JSON-encoded rather than delimiter-joined. `provenance.source`
  // is free text and `human` provenance is an expected input, so a tab or
  // newline pasted into a citation would otherwise shift field boundaries and
  // let two different edge sets serialise identically. A hash that can collide
  // is a hash that silently fails to move when the entitlement basis changes,
  // which is the exact failure this hash exists to prevent.
  const lines: string[] = [];
  for (const id of docIds) {
    lines.push(JSON.stringify(['doc', id, byId.get(id)?.sha256Normalized ?? '']));
  }
  for (const e of included) {
    lines.push(
      JSON.stringify([
        'edge',
        e.edgeId,
        e.kind,
        e.from,
        e.to,
        e.provenance.type,
        e.provenance.source,
        e.provenance.recordedOn,
      ]),
    );
  }

  return {
    docIds,
    edgeIds: included.map((e) => e.edgeId),
    sha256: sha256Hex(lines.join('\n')),
  };
}
```

```ts
/**
 * Mechanical evidence checking — the anti-hallucination control.
 *
 * A conclusion in a verification result is only as good as the text behind it,
 * so every quote is checked as a literal substring of the exact document it
 * names, at the hash it names. A fabricated quote fails the build, not the
 * review, which is what lets a reviewer trust a dossier without re-reading the
 * law.
 *
 * `absence` is the item that would otherwise be pure assertion. Re-running the
 * search makes it checkable — but only lexically. A search can prove a phrase
 * does not occur; it cannot prove no economically equivalent criterion exists
 * under different words. That is a legal judgment, so absence may never be the
 * sole evidence for a conclusion.
 */

import type { LoadedCorpus } from './store';
import { normalizeWhitespace } from './normalize';

export interface QuoteEvidence {
  kind: 'quote';
  docId: string;
  /** The document hash at the time of quoting. Must still match. */
  sha256Normalized: string;
  text: string;
}

export interface AmendmentChainEvidence {
  kind: 'amendment_chain';
  hops: Array<{ edgeId: string; quote: QuoteEvidence }>;
}

export interface CrossReferenceEvidence {
  kind: 'cross_reference';
  edgeId: string;
  from: QuoteEvidence;
  to: QuoteEvidence;
}

export interface AbsenceEvidence {
  kind: 'absence';
  docIds: string[];
  term: string;
}

export type EvidenceItem =
  | QuoteEvidence
  | AmendmentChainEvidence
  | CrossReferenceEvidence
  | AbsenceEvidence;

export interface EvidenceCheckResult {
  ok: boolean;
  problems: string[];
}

/**
 * Comparison form: whitespace-normalized, then case-folded. Casing must not
 * hide a hit.
 *
 * Uses normalizeWhitespace, NOT normalize: both sides of every comparison here
 * are already-extracted text, and re-running extraction over it would decode
 * entities a second time and shift the haystack out from under the quote.
 */
function searchable(text: string): string {
  return normalizeWhitespace(text).toLowerCase();
}

function checkQuote(q: QuoteEvidence, corpus: LoadedCorpus, label: string, problems: string[]): void {
  if (q.text.trim().length === 0) {
    problems.push(`${label}: quote is empty`);
    return;
  }

  let expectedHash: string;
  try {
    expectedHash = corpus.document(q.docId).sha256Normalized;
  } catch {
    problems.push(`${label}: quote names ${q.docId}, which the corpus does not hold`);
    return;
  }

  if (expectedHash !== q.sha256Normalized) {
    problems.push(
      `${label}: quote pins ${q.docId} at hash ${q.sha256Normalized.slice(0, 12)}…, corpus holds ${expectedHash.slice(0, 12)}…`,
    );
    return;
  }

  const haystack = searchable(corpus.normalizedText(q.docId));
  if (!haystack.includes(searchable(q.text))) {
    problems.push(`${label}: quote not found in ${q.docId}: "${q.text.slice(0, 80)}"`);
  }
}

function edgeById(corpus: LoadedCorpus, edgeId: string) {
  for (const d of corpus.index.documents) {
    for (const e of d.edges) {
      if (e.edgeId === edgeId) return e;
    }
  }
  return undefined;
}

/**
 * Checks one evidence set — the items backing a single conclusion. Returns
 * every problem found rather than the first, so a result can be repaired in one
 * pass instead of one round trip per defect.
 */
export function checkEvidenceSet(items: EvidenceItem[], corpus: LoadedCorpus): EvidenceCheckResult {
  const problems: string[] = [];

  if (items.length === 0) {
    return { ok: false, problems: ['evidence set contains no evidence'] };
  }

  if (items.every((i) => i.kind === 'absence')) {
    problems.push(
      'absence is the sole evidence for this conclusion: lexical absence cannot establish that no equivalent criterion exists under different words',
    );
  }

  items.forEach((item, i) => {
    const label = `evidence[${i}]`;

    if (item.kind === 'quote') {
      checkQuote(item, corpus, label, problems);
      return;
    }

    if (item.kind === 'amendment_chain') {
      if (item.hops.length === 0) {
        problems.push(`${label}: amendment chain has no hops`);
        return;
      }
      item.hops.forEach((hop, h) => {
        const hopLabel = `${label}.hops[${h}]`;
        if (edgeById(corpus, hop.edgeId) === undefined) {
          problems.push(`${hopLabel}: names edge ${hop.edgeId}, which the corpus does not hold`);
        }
        checkQuote(hop.quote, corpus, hopLabel, problems);
      });
      return;
    }

    if (item.kind === 'cross_reference') {
      const edge = edgeById(corpus, item.edgeId);
      if (edge === undefined) {
        problems.push(`${label}: names edge ${item.edgeId}, which the corpus does not hold`);
      } else if (edge.from !== item.from.docId || edge.to !== item.to.docId) {
        problems.push(
          `${label}: edge ${item.edgeId} does not connect ${item.from.docId} to ${item.to.docId}`,
        );
      }
      checkQuote(item.from, corpus, `${label}.from`, problems);
      checkQuote(item.to, corpus, `${label}.to`, problems);
      return;
    }

    // absence
    if (item.docIds.length === 0) {
      problems.push(`${label}: absence claim names no documents`);
      return;
    }
    if (item.term.trim().length === 0) {
      problems.push(`${label}: absence claim has an empty term`);
      return;
    }
    const needle = searchable(item.term);
    for (const docId of item.docIds) {
      let text: string;
      try {
        text = corpus.normalizedText(docId);
      } catch {
        problems.push(`${label}: absence claim names ${docId}, which the corpus does not hold`);
        continue;
      }
      if (searchable(text).includes(needle)) {
        problems.push(`${label}: "${item.term}" occurs in ${docId}, so it is not absent`);
      }
    }
  });

  return { ok: problems.length === 0, problems };
}
```

```ts
/**
 * Corpus ingest — the only component that touches the network.
 *
 * Everything downstream of the received bytes is deterministic and tested from
 * fixtures: bytes to normalization to hashing to a validated index entry. The
 * fetch itself is not, which is why it is isolated here rather than spread
 * through the verification code.
 *
 * Ingest does NOT discover legal relationships. Edges are either supplied by a
 * human and validated, or derived from published ELI/CELEX metadata. Working
 * out that one instrument amends another by reading them is a legal judgment,
 * and putting it inside the agent-free layer would smuggle reasoning into the
 * one part of the system whose value is that it contains none.
 */

import { mkdirSync, readFileSync, writeFileSync } from 'node:fs';
import { dirname, join } from 'node:path';
import type { CorpusDocument, CorpusEdge, CorpusIndex } from '../corpus/types';
import { parseCorpusIndex, verifyCorpusIntegrity } from '../corpus/schema';
import { normalize, NORMALIZER_VERSION } from '../corpus/normalize';
import { sha256Hex } from '../corpus/hash';

export interface IngestInput {
  docId: string;
  /** Filename stem for both stored forms. */
  slug: string;
  serves: string[];
  title: string;
  url: string;
  versionLabel: string;
  /** ISO date. Passed in, never read from the clock here. */
  retrievedOn: string;
  rawText: string;
  edges: CorpusEdge[];
}

/**
 * Bytes to a validated index entry. Throws if the result would not satisfy the
 * schema, so an invalid entry can never reach index.json.
 */
export function buildDocumentEntry(input: IngestInput): {
  entry: CorpusDocument;
  rawText: string;
  normalizedText: string;
} {
  const normalizedText = normalize(input.rawText);

  const entry: CorpusDocument = {
    docId: input.docId,
    serves: input.serves,
    title: input.title,
    url: input.url,
    versionLabel: input.versionLabel,
    retrievedOn: input.retrievedOn,
    rawPath: `raw/${input.slug}.html`,
    normalizedPath: `normalized/${input.slug}.txt`,
    sha256Raw: sha256Hex(input.rawText),
    sha256Normalized: sha256Hex(normalizedText),
    normalizerVersion: NORMALIZER_VERSION,
    edges: input.edges,
  };

  // Validate the single entry immediately; a bad row never reaches the index.
  parseCorpusIndex({ updated: input.retrievedOn, documents: [entry] });

  return { entry, rawText: input.rawText, normalizedText };
}

/** Adds or replaces a document, keeping the index sorted for clean diffs. */
export function mergeIntoIndex(index: CorpusIndex, entry: CorpusDocument): CorpusIndex {
  const documents = index.documents.filter((d) => d.docId !== entry.docId);
  documents.push(entry);
  documents.sort((a, b) => (a.docId < b.docId ? -1 : a.docId > b.docId ? 1 : 0));
  return { updated: entry.retrievedOn, documents };
}

interface FetchOutcome {
  ok: boolean;
  text: string;
  error?: string;
}

/** A failed fetch is recorded as unreachable. It is never treated as empty. */
async function fetchDocument(url: string): Promise<FetchOutcome> {
  try {
    const response = await fetch(url, { headers: { accept: 'text/html,text/plain' } });
    if (!response.ok) {
      return { ok: false, text: '', error: `HTTP ${response.status} ${response.statusText}` };
    }
    return { ok: true, text: await response.text() };
  } catch (err) {
    return { ok: false, text: '', error: err instanceof Error ? err.message : String(err) };
  }
}

function usage(): never {
  console.error(
    [
      'Usage:',
      '  npm run ingest -- --url <url> --doc-id <DOC-...> --slug <stem> \\',
      '    --serves SRC-001[,SRC-004] --title "<title>" --version-label "<label>" \\',
      '    --retrieved-on YYYY-MM-DD [--corpus-dir <dir>] [--edges <edges.json>]',
      '',
      'Edges, when supplied, are a JSON array of CorpusEdge objects. Each needs a',
      'complete provenance block. Ingest validates them; it does not invent them.',
    ].join('\n'),
  );
  process.exit(2);
}

function arg(argv: string[], name: string): string | undefined {
  const i = argv.indexOf(`--${name}`);
  if (i === -1) return undefined;
  return argv[i + 1];
}

export async function main(argv: string[]): Promise<void> {
  const url = arg(argv, 'url');
  const docId = arg(argv, 'doc-id');
  const slug = arg(argv, 'slug');
  const serves = arg(argv, 'serves');
  const title = arg(argv, 'title');
  const versionLabel = arg(argv, 'version-label');
  const retrievedOn = arg(argv, 'retrieved-on');
  const corpusDir = arg(argv, 'corpus-dir') ?? 'corpus';
  const edgesPath = arg(argv, 'edges');

  if (!url || !docId || !slug || !serves || !title || !versionLabel || !retrievedOn) usage();

  const edges: CorpusEdge[] = edgesPath ? JSON.parse(readFileSync(edgesPath, 'utf8')) : [];

  const outcome = await fetchDocument(url);
  if (!outcome.ok) {
    console.error(`UNREACHABLE ${url}: ${outcome.error}`);
    console.error('Nothing was written. An unreachable source is not a source that said nothing.');
    process.exit(1);
  }

  const { entry, rawText, normalizedText } = buildDocumentEntry({
    docId,
    slug,
    serves: serves.split(',').map((s) => s.trim()),
    title,
    url,
    versionLabel,
    retrievedOn,
    rawText: outcome.text,
    edges,
  });

  const indexPath = join(corpusDir, 'index.json');
  let index: CorpusIndex;
  try {
    index = parseCorpusIndex(JSON.parse(readFileSync(indexPath, 'utf8')));
  } catch {
    index = { updated: retrievedOn, documents: [] };
  }

  const merged = mergeIntoIndex(index, entry);
  verifyCorpusIntegrity(merged);

  for (const [path, contents] of [
    [join(corpusDir, entry.rawPath), rawText],
    [join(corpusDir, entry.normalizedPath), normalizedText],
  ] as const) {
    mkdirSync(dirname(path), { recursive: true });
    writeFileSync(path, contents, 'utf8');
  }
  mkdirSync(dirname(indexPath), { recursive: true });
  writeFileSync(indexPath, `${JSON.stringify(merged, null, 2)}\n`, 'utf8');

  console.log(`Ingested ${entry.docId}`);
  console.log(`  raw        ${entry.rawPath}  ${entry.sha256Raw.slice(0, 12)}…`);
  console.log(`  normalized ${entry.normalizedPath}  ${entry.sha256Normalized.slice(0, 12)}…`);
  console.log(`  edges      ${entry.edges.length}`);
  if (entry.edges.length === 0) {
    console.log('  No edges recorded. Ingest does not infer them — supply them with --edges.');
  }
}

const invokedDirectly = process.argv[1] !== undefined && process.argv[1].endsWith('ingest.ts');
if (invokedDirectly) {
  await main(process.argv.slice(2));
}
```
